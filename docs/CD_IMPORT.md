# CD取り込み（Windows）

上部の「CD取込」から専用画面を開きます。

1. 音楽CDをセットして取り込み画面を開きます。「開くときにCDを読み込む」は初期値ONで、選択ドライブを自動で読み込みます。OFFの場合やCDを交換した場合は、ドライブを選択して「CDを読み込む」を押してください。ON／OFFは次回も保持します。
2. 「曲情報を取得」でMusicBrainzへCDの曲構成を照会します。「自動で反映」は初期値ONで、取得した最初の候補を反映します。違っていれば候補を選び「候補を反映」を押してください。自動反映をOFFにすると、取得後も「候補を反映」を押すまで入力内容を維持します。ON／OFFは次回も保持します。音声やローカルのパスは送信しません。曲数・曲時間が近いだけの候補は特に確認してください。
3. アルバム名・アルバムアーティスト・年・Disc番号／総枚数を確認。表には保存するタグを表示し、右側の列は横スクロールで確認できます。曲名・曲ごとのアーティスト・ジャンル・作曲者・コメントは表で編集できます。アルバム等の共通項目は上部の入力と連動します。曲情報がない場合は手入力できます。
   各曲の「▶ 試聴」または下部の「選択曲を試聴」でCDから直接再生できます。試聴中は下部のシークバーをドラッグして再生位置を変更できます。「試聴停止」で止まり、別の曲を押すと先頭から切り替わります。試聴はその曲の終端で終了します。取り込み開始・CD再読込・画面を閉じるときは試聴を停止します。試聴開始時はメイン画面の音楽再生を停止します。
4. FLACまたはMP3を選択。MP3は192／256／320kbps、初期値320kbps。FLACは44.1kHz・16bit・ステレオの可逆圧縮です。形式・ビットレート・保存先は次回も保持します。
5. 読み取り中は各曲の進捗を横長のバーとパーセントで表示します。エンコード・検証中は処理中の表示に切り替わります。取り込み完了後に閉じるとライブラリに登録します。通常のDIRアルバムとしてAndroidへ転送できます。
6. 「⏏ CDを取り出す」で選択したドライブのトレイを開けます。試聴中は自動停止してから取り出し、取り込みなどの処理中は操作できません。取り出した後も取り込み済みのアルバムは保持され、画面を閉じると登録されます。

1枚組（総枚数1）は `保存先/アーティスト - アルバム/01 曲名.flac` とし、Disc1フォルダーは作りません。複数枚組だけ `保存先/アーティスト - アルバム/Disc1/01 曲名.flac` に保存します。2枚目以降は同じ保存先・アルバム名・アルバムアーティストを指定してDisc番号を変更します。1枚組の既存アルバムや複数枚組の既存Discは上書きしません。既に取り込んだフォルダー構成は自動変更しません。

## オフセット補正とAccurateRip照合（Windows v0.89.0以降）

Windows v0.89.0以降の機能です。2026-09-29に、hp HLDS DVDROM DUD1N（MDM2）と8曲の音楽CDを使用し、+6サンプル補正で全8曲のオンライン照合がv2・信頼度14で一致しました。診断は音声をメモリー上へ読み取る方式で、設定・ライブラリー・音声ファイルは変更していません。末尾の6サンプルは無音補完されることも確認しました。この実機診断は、取り込み画面から保存する一連の操作や、他のCD・機種すべての検証を意味しません。

- 「AccurateRip照合」は初期値ON。CD構成から照会し、圧縮前の44.1kHz・16bit・ステレオPCMでv1/v2チェックサムを計算します。FLAC／MP3の両方で使用できます。音声ファイルや曲名は送信せず、照会URLにはCD識別情報を使用します。データベースへの結果投稿は行いません。
- 曲一覧の「AccurateRip結果」と完了メッセージに、一致・信頼度／不一致／未登録／通信・応答エラーを表示します。照合OFFにもできます。未登録や不一致は音声破損の断定ではなく、別プレスや補正値の違いもあり得ます。不一致・未登録・通信失敗でも、従来の読み取り・保存検証を通れば保存します。
- 「未設定ドライブの補正値を自動取得」は初期値ON。CD読込時に、保存済み補正設定がないドライブについてAccurateRip公式一覧をHTTPSで取得し、メーカー・型番が完全一致する登録値を設定して「補正値を使用」をONにします。公式が明記するメーカー表記の別名（HL-DT-ST／LG Electronics等）と大文字小文字・空白のみ正規化し、型番の部分一致や他メーカーの値は使いません。登録値の一致率が100%未満、値が複数、除外対象、未登録の場合は自動設定しません。
- 保存済み設定（手入力や補正OFFを含む）は自動取得で上書きしません。「補正値を取得」ボタンで再照会でき、既存設定の置き換えは確認してから行います。自動取得をOFFにすると手動取得／手入力で設定します。通信失敗時も設定を保持し、CDの取り込み操作を続けられます。一覧取得は最大15秒・4MiB、同じ画面内の自動取得では取得済み一覧を再利用し、ボタン操作は再取得します。一覧の取得にドライブ情報や音声を送信しません。
- 手入力も引き続き可能です。「補正値を使用」をONにし、EAC／AccurateRipと同じ符号で入力します。+Nは生の読み取り位置をNステレオサンプル進めます。範囲は-5880〜+5880で、補正後も曲の長さは維持します。未設定時は補正OFF・0。0が正しい機種も、確認済みならON・0を指定できます。
- ドライブの型番・ファームウェア・識別番号で補正設定を保存し、公式一覧由来の設定には取得元も記録します。識別できないドライブでは自動復元しません。ドライブ文字だけでは復元せず、機器を変更した場合はCDを再読込して設定を確認してください。型番の登録値取得は実機の自動測定ではありません。製造ロットやファームウェアで違う可能性もあるため、実際の取り込み後にAccurateRip照合結果を確認してください。基準CDでの自動測定は未実装です。
- 曲間は隣の曲の領域も読み出して補正します。音声TOCの外へのオーバーリードには未対応なので、CDの先頭・末尾からはみ出す部分は無音で補い、補ったサンプル数をログに記録します。その部分の元音声を回復したという意味ではありません。AccurateRip照合もディスク端の一部を除外するため、一致をCD全サンプルの完全保存と同一視しないでください。
- `cd-import.log` にドライブ識別情報、補正値、CD識別子、曲別v1/v2チェックサム、信頼度と照合結果を残します。ドライブの識別番号が含まれる場合があるため、ログを公開する際は確認してください。
- 通信はHTTPS、待機時間は最大15秒、応答サイズは最大2MiB。途中中断は取り込みを中断しますが、通信失敗だけでは取り込みを止めません。不正・欠けた応答を「不一致」として扱いません。別プレスのオフセット探索・エラー音声の修復は未対応です。

AccurateRipの利用条件は[公式サイト](https://accuraterip.com/)を参照してください。非商用利用は無料、商用利用は事前合意が必要と案内されています。本機能は公式認証・提携を表すものではありません。補正値は[公式ドライブ一覧](https://www.accuraterip.com/driveoffsets.htm)で確認できます。

実装確認に用いた仕様参考：[チェックサム参照実装](https://github.com/leo-bogert/accuraterip-checksum)、[Python Audio ToolsのCD識別・応答形式](https://github.com/tuffy/python-audio-tools/blob/master/audiotools/accuraterip.py)。アルゴリズム・通信形式を確認し、本アプリ用に独立実装しています。

## 検証と安全性

- 各ブロックは2回一致することを確認。最大4回まで読み直し、不一致や読み取り失敗で中断します。
- FLACは全音声を再デコードして読み取ったPCMとSHA-256で照合します。MP3は全デコード・曲長・タグを確認します。
- ドライブのキャッシュを無効化したセキュアリッピングは未対応です。2回一致したことはCD原盤との完全一致を保証しません。オフセット補正・AccurateRip照合は上記を参照してください。
- 通常の音楽CDのみ対応。データ混在、プリエンファシス、4チャンネルCD、HTOAの取り出し、コピー保護回避には対応しません。
- 「中断」は現在のドライバー読み取りが戻った後に処理されます。保存中に強制終了しないでください。
- 取り込み中は予約形式 `.zip-folder-<GUID>` の一時フォルダーを使用し、ライブラリには登録しません。選択曲の変換・検証完了後にDiscを公開します。
- 失敗・中断時の一時データは復旧確認用に残し、その場所を表示します。自動削除しません。`cd-import.log` に処理結果を記録します。
- CDや既存音楽は書き換えません。MusicBrainz未登録CDは手入力が必要です。ジャケット画像の自動取得は初期版の取り込み画面には含みません。
