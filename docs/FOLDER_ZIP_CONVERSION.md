# DIRアルバムからZIP.MP3への変換

## 編集バックアップの7日間保管

設定の「編集バックアップを7日後に自動削除」で有効・無効を切り替えられます。対象は、登録中の有効な音楽フォルダーとタグバックアップ保存先にある、アプリ形式の切り抜き・回転・タグ編集バックアップだけです。通常の音楽・画像、手動バックアップ、変換途中の一時フォルダーや復旧ファイルは対象外です。

既存のファイルも初回確認から7日間保管します。コピー元から引き継がれた古い更新日時では判定しません。アプリ起動約1分後と、起動中は約1時間ごとに確認し、バックアップが変更されていれば保管期間を数え直します。元ファイルの欠落・読み取り失敗・リンク・使用中などで安全確認できない場合は削除しません。タグバックアップ専用フォルダーで元ファイルの対応が曖昧な場合も残します。編集中や終了処理中は削除しません。削除対象は再照合・ロック後に完全削除され、ごみ箱からは復元できません。確認日時と直近の削除履歴はアプリデータ内の `edit-backup-retention.json` に保存します。

## ZIP.MP3からDIRへの逆変換

右クリック →「ZIP.MP3をDIRに変換…」。現在のファイル名から末尾の.zip.mp3を除いたフォルダーへ展開します。全収録物が共通の親フォルダーに入っている場合のみ、その一段を除きます。サブフォルダーと空フォルダーは保持します。同名の展開先は上書きしません。Disc1・Disc2など複数のフォルダーに音源がある場合も、それぞれの構造を保持して全曲を検証し、全体を一つのDIRアルバムとして登録します。同じ曲名のファイルも相対パスで区別し、お気に入り・再生履歴・保存歌詞を引き継ぎます。変換先には管理ファイル `.vccs-folder-album.json` を作成します。このファイルにより、再起動・再スキャン後もディスクごとに分離しません。通常の未変換フォルダーの読み込みは変更しません。

変換と関連データの引き継ぎが完了した場合、元ZIPを保管しても一覧には変換後のDIRだけ表示します。元ZIPのサイズ・更新日時が変わった場合や、変換先がなくなった場合は元ZIPが再び検出されます。失敗時の `.zip-folder-<32桁ID>` 一時フォルダーはライブラリに登録せず、過去のキャッシュ内の登録も読み込み時に除外します。一時ファイルそのものは自動削除しません。

変換開始時に元ZIPの自動削除を含めて確認します。展開内容の全ファイル照合・曲の読み込み・関連データの引き継ぎが完了した後、展開先と元ZIPを再検証して元ZIPを完全削除します。ごみ箱には入りません。時間経過だけで削除することはありません。展開先または元ZIPが変わった場合、検証に失敗した場合、削除開始前に終了要求があった場合は元ZIPを残します。不正パス・リンク・Windows上の同名衝突は拒否します。展開失敗時には元ZIPを保持し、部分展開データの場所をエラーに表示します。

双方向で画像の用途・回転・ケース設定、追加画像、保存歌詞、お気に入り、再生履歴を引き継ぎます。往復時に既存の管理画像データが残っている場合は、before-conversion付きの名前へ退避してから現在の情報をコピーします。処理中の終了要求は後処理まで保留し、まだ確認していない元データの削除は行いません。

アルバム一覧の右クリック → 「DIRをZIP.MP3に変換…」。MP3音源のDIRアルバムを対象にします。現在のZIP再生がMP3専用のため、FLAC/WAV等の音源を含むアルバムや、別アルバムを入れ子にしたフォルダーは変換しません。

音源・画像・歌詞・その他のファイルと空ディレクトリーをUTF-8名の無圧縮ZIPへ格納し、同じ場所に「フォルダー名.zip.mp3」を作成します。同名の出力先は上書きしません。元データは変換時には削除しません。

全ファイルのSHA-256一致と音源の読み取りを検証し、画像の用途・回転等の設定、保存歌詞、お気に入り、再生履歴を引き継ぎます。その後の確認で「はい」を選んだ場合のみ、ZIPと元データを再検証して元フォルダーを完全削除します。ごみ箱は使用しません。必要なら作成したZIPから展開して復元してください。

削除前に全ファイルをロックし、変更や差し替えを防ぎます。再帰削除は行わず、検証済みのファイルだけを削除します。追加・変更、リンク、ロック失敗等がある場合は中止します。削除途中の通信・権限エラーでは一部の元ファイルが残る場合がありますが、ZIPは保持します。

「いいえ」では元フォルダーとZIPの両方を残します。その場合は自動検出で両方が一覧に載ることがあります。音源形式を変更・再エンコードする機能ではありません。ファイル内容とフォルダー構造を保存するもので、NTFSのアクセス権等を復元するバックアップではありません。
