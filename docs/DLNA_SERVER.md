# DLNA／UPnP AV配信（Windows v0.89.0以降）

Windows v0.89.0以降で、選択したアルバムを家庭内LANの対応アプリ・ネットワークプレーヤーから閲覧して再生します。DLNA認証取得を意味するものではなく、iPhone・テレビ・オーディオ機器との実機互換性は未確認です。

## 使い方

1. PCと再生機器を同じ信頼できる家庭内LANへ接続します。
2. Windowsアプリ上部の「DLNA配信」を開き、使用するLAN接続を選択します。VPN・公衆Wi-Fi・ゲストネットワークは選ばないでください。
3. 共有したいアルバムにチェックします。検索・表示中の全選択・全解除ができます。非表示にした音楽フォルダーは候補に含めません。
4. 「選択したアルバムを、信頼できる家庭内LANに公開する」にチェックして、配信を開始します。
5. Windowsファイアウォールの許可が必要な場合は、プライベートネットワークだけ許可します。アプリはファイアウォールを自動変更／無効化しません。
6. 再生機器側で `Virtual CD Collection Studio` を選び、Albums・Artists・All tracksから曲を選びます。iPhoneはVLC・mconnectなどのUPnP／DLNA対応アプリを使い、そのアプリのローカルネットワークアクセスを許可してください。
7. 「配信を停止」で終了します。次回アプリ起動時は必ず配信OFFです。共有対象の自動再公開はしません。

発見用にUDP 1900、音楽配信に画面に表示されたHTTPのTCPポートを使用します。複数のLAN接続がある場合は、再生機器と同じサブネットを選びます。ルーターのクライアント分離・マルチキャスト制限・VPN・ファイアウォールにより発見できない場合があります。ルーターのポート転送は不要です。

## 画面を閉じても配信を続ける

設定の「DLNA配信中は、閉じてもバックグラウンドで動作する（通知領域に常駐）」をONにして保存します。初期値はOFFです。

- 配信中にメイン画面の×を押すと、画面を隠してWindows右下の通知領域（隠れているアイコンの中を含む）に常駐します。
- アイコンのダブルクリック、または右クリックの「画面を表示」で戻ります。
- 右クリックの「DLNA配信を停止」は配信だけ停止し、「アプリを終了」は保存・取り込みなどの保護を維持したままアプリを終了します。
- 配信を開始していないときは、この設定だけで常駐しません。従来の「タスクバーへ最小化する」は別の設定で、両方ONなら配信中は通知領域の設定を優先します。
- Windowsサービス化やPC起動時の自動配信ではありません。PCのスリープ・シャットダウン・ネットワーク切断中は配信できません。

## 内容・対応範囲

- 登録済み情報を使い、開始時に全フォルダーを再スキャンしません。選択したアルバムのみのスナップショットを公開します。
- 配信準備はキャンセルできます。2,000件を超える一覧は1,000件ごとのフォルダーに分け、一覧を一括取得する機器でも閲覧できるようにします。
- フォルダー内のMP3・FLAC・WAV・M4Aを元の形式で配信します。相手の機器がその形式・サンプリング周波数に対応する必要があります。
- ZIP／ZIP.MP3内のMP3はStore・Deflateに対応。現在のZIPのエントリ名とサイズを確認し、古いキャッシュの位置情報から別の内容を送信しません。Storeは一時ファイルへ展開せずに曲を読みます（範囲取得で曲頭から読み進める場合があります）。DeflateはHTTP要求ごとに一時展開し、送信完了・切断・停止時に一時ファイルを削除します。要求間の再利用はなく、途中位置の取得で再展開する場合があります。
- Deflateは1曲128 MiB、HTTP同時処理は4件まで。一時展開量は合計最大512 MiBです。保存先はWindowsの一時フォルダー内 `ZipMp3Player/Dlna` で、音楽ライブラリやAndroid転送キャッシュとは別です。
- CUEの分割トラック・CD-DA・暗号化ZIP・ZIP内のMP3以外・未対応／解析失敗曲は除外します。CUEトラックの代わりに全ディスク音源を誤配信しません。
- ジャケットは既存の用途割り当てを使った最大160pxのJPEGです。専用ブックレット操作・歌詞同期・3Dケースは配信しません。
- HTTP GET／HEAD・バイト範囲取得に対応。DLNAの時間指定TimeSeek・ギャップレス・機器への再生指示・形式変換・クラウド配信は保証／実装していません。
- 曲情報・画像・共有対象の変更は停止→再開で反映します。配信中に元音楽／ZIPが変更された場合は、古い位置から別データを送らず取得を失敗させます。共有アルバムが登録から外れたり、フォルダーが非表示になったりすると配信を停止します。

## セキュリティ

通常のDLNA機器と接続するため、QRコード認証・パスワード・通信暗号化は使いません。同じLANの機器から選択した曲名・音楽・ジャケットを読み取れます。相手を個別承認する機能はありません。

プライベートIPv4アドレスを一つ選び、同じサブネットの要求に限定します。公開IPv4・IPv6・インターネット越し接続には対応しません。Windowsのネットワーク種別を自動変更せず、プライベートネットワーク用の許可と組み合わせて使ってください。

HTTPは選択した曲・画像の内部IDのみを受け付けます。ローカルの保存パスを一覧に含めず、任意パスの読み取り・アップロード・削除はできません。SOAP XMLのDTD／外部エンティティを拒否し、イベント通知先は要求した機器自身のIPに限定。DNS名・別ホスト・リダイレクト経由の通知を許可しません。

## 検証と参考資料
