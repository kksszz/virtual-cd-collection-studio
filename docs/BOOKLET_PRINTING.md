# ブックレット・ジャケット画像の印刷（Windows開発版）

公開済みWindows v0.88.0には未搭載です。対応するWindows開発版のブックレットビューアーで「印刷…」またはCtrl+Pを使います。

1. アルバムのブックレットを開き、印刷したいページを確認します。
2. 「現在のページ」「すべてのページ」「ページ範囲を指定」を選びます。範囲はビューアーの1始まりの表示順です。1画像を用紙1ページへ印刷し、見開き画像も1ページとして扱います。
3. 「用紙に収める」は縦横比を保ち、印刷可能範囲と余白の内側へ中央配置します。「幅をmmで指定」は各画像に同じ幅を適用し、高さは縦横比から求めます。例：1面120mm、見開き240mm。大小・縦横の異なる画像を一緒に印刷する場合は、別のジョブに分けて設定してください。
4. 余白は用紙端から0〜50mmで指定します（初期値10mm）。プリンター固有の印刷できない領域も避けます。
5. 「プリンターを選ぶ…」でWindowsの印刷画面を開き、プリンター・用紙サイズ・向き・部数などを確認して印刷します。どちらの画面でもキャンセルすれば印刷ジョブは送信しません。

印刷前に対象画像の読み取りとサイズを確認します。幅指定で用紙に収まらない場合は、切り落としたり勝手に縮小したりせず中止します。用紙を大きくする、横向きにする、幅や余白を変更する、または「用紙に収める」を使ってください。

## 出力範囲と注意事項

- ビューアーのズーム・影・中央の折り目表現・操作ボタンは含めず、ページ画像だけを印刷します。スライドショーは印刷操作時に停止します。元の音楽・画像ファイルは変更しません。
- 現在のビューアーで使う画像を読み直して印刷します（長辺最大3000ピクセルの読込経路）。スキャンの全解像度を保証するものではありません。用紙・プリンター・画像解像度によって仕上がりは変わります。
- 幅指定は画像のDPI情報から実物寸法を推測するものではありません。元のCDに合わせる場合は実際の寸法を測り、mmで入力してください。
- 印刷キューへの送信は、紙への印刷完了を意味しません。インク・用紙不足やプリンターの状態はキューで確認してください。送信途中のエラーは部分的なジョブが残る場合があります。
- Windowsに導入済みのPDFプリンターを選べばPDFとして保存できます。保存先はプリンター側のダイアログで指定します。
- 通常の紙への画像印刷です。製本用の面付け、両面ページの組み合わせ、トンボ、折り目の自動生成、CD盤面への直接印刷、3Dプリンター出力は実装していません。
- 自分で利用する権利のある画像を使用してください。紙へ出力しても画像の権利は変わりません。

開発時はページ範囲・縦横比・mm寸法・余白・印刷可能領域をプリンターへ送信しないレンダリングで検証します。実プリンターの給紙・発色・紙面寸法の実機確認は別途必要です。
