# ブックレット・ジャケット画像の印刷（Windows v0.89.0以降）

Windows v0.89.0以降のブックレットビューアーで「印刷…」またはCtrl+Pを使います。旧版v0.88.0には含まれません。

1. アルバムのブックレットを開き、印刷したいページを確認します。
2. 「現在のページ」「すべてのページ」「ページ範囲を指定」を選びます。範囲はビューアーの1始まりの表示順です。見開き画像も1画像として扱い、左右には切り分けません。
3. 「1枚にまとめる」で、用紙1枚あたり1・2・4・6・9ページを選びます。2・4・6・9ページを選んだとき、対象が「現在のページ」なら自動で「すべてのページ」へ切り替わります。手動指定したページ範囲は維持し、集約選択後に「現在のページ」を手動で選ぶこともできます。選択した画像を左→右、上→下の順で配置し、最後の空き枠は白紙になります。2ページは縦用紙で上下・横用紙で左右、6ページは縦用紙で2列×3行・横用紙で3列×2行です。4ページは2列×2行、9ページは3列×3行です。
4. 「配置枠に収める」は各画像の縦横比を保って枠内へ中央配置します。「幅をmmで指定」は各画像に同じ幅を適用し、高さは縦横比から求めます。集約時も指定幅を維持し、枠に収まらなければ中止します。
5. 余白は用紙端から0〜50mm（初期値10mm）、画像間隔は0〜30mm（初期値5mm）です。プリンター固有の印刷できない領域も避けます。
6. プレビューは設定画面内に表示します。横幅が広いと右側、狭いと下側へ配置し、ページ範囲・集約数・幅・余白・画像間隔の変更を自動反映します。矢印で用紙を切り替え、空き枠も確認できます。プリンター選択前はA4縦／横・印刷不可領域5mmの仮表示で、実際の用紙設定とは異なります。
7. 「プリンター・用紙を選ぶ…」でWindowsの画面からプリンター・用紙・向き・部数を選びます。この画面で確定してもまだジョブは送信しません。同じプレビュー欄が実用紙・印刷可能領域へ切り替わります。余白・集約数などを引き続き調整でき、用紙や向きを変える場合は再度プリンター・用紙を選びます。「この内容で印刷」を押したときだけ送信します。どの画面でもキャンセルすれば印刷ジョブは送信しません。ドライバー側の集約設定は二重集約を避けるため1ページ／枚に設定します。

入力途中・更新中・画像読込失敗時は古いプレビューを消し、印刷を無効にします。連続した変更では最新の設定のみを反映します。表示中の用紙に必要な画像だけを読み、縮小画像を最大12枚まで一時保持します。元画像の寸法で配置を計算し、印刷時は通常の画像読込経路で全対象を再確認します。

印刷前に対象画像の読み取りとサイズを確認します。幅指定で配置枠に収まらない場合は、切り落としたり勝手に縮小したりせず中止します。用紙を大きくする、横向きにする、1枚あたりのページ数を減らす、幅や余白を変更する、または「配置枠に収める」を使ってください。

## 出力範囲と注意事項

- ビューアーのズーム・影・中央の折り目表現・操作ボタンは含めず、ページ画像だけを印刷します。スライドショーは印刷操作時に停止します。元の音楽・画像ファイルは変更しません。
- 現在のビューアーで使う画像を読み直して印刷します（長辺最大3000ピクセルの読込経路）。スキャンの全解像度を保証するものではありません。用紙・プリンター・画像解像度によって仕上がりは変わります。
- 幅指定は画像のDPI情報から実物寸法を推測するものではありません。元のCDに合わせる場合は実際の寸法を測り、mmで入力してください。
- 印刷キューへの送信は、紙への印刷完了を意味しません。インク・用紙不足やプリンターの状態はキューで確認してください。送信途中のエラーは部分的なジョブが残る場合があります。
- Windowsに導入済みのPDFプリンターを選べばPDFとして保存できます。保存先はプリンター側のダイアログで指定します。
- 通常の紙への画像印刷です。製本用の面付け、両面ページの組み合わせ、トンボ、折り目の自動生成、CD盤面への直接印刷、3Dプリンター出力は実装していません。
- 自分で利用する権利のある画像を使用してください。紙へ出力しても画像の権利は変わりません。

開発時はページ範囲・集約枚数・配置順・縦横比・mm寸法・余白・印刷可能領域・プレビューをプリンターへ送信しないレンダリングで検証します。実プリンターの給紙・発色・紙面寸法・ドライバー固有の設定の実機確認は別途必要です。
