# アルバム画像のスキャン（Windows）

アルバムを選択し、「アルバム画像」の操作を展開して「スキャン」を押します。

## TWAIN（EPSON画質設定を優先）

EPSON GT-S650のネイティブTWAINドライバーを優先選択します。64bitプレーヤーから、同梱の32bit連携プログラムで接続します。EPSON Scanの単独アプリは閉じてください。

通常は「1枚スキャン」で設定画面を表示せずにTWAINで読み取ります。解像度・カラーをプレーヤーで指定できます（初期値600dpi・24bit）。EPSON独自の補正や保存プリセットは、この方法では継承を保証できません。

必要な場合だけ「EPSON／TWAINの詳細設定画面を表示」をONにすると、ドライバー画面が開きます。EPSON Scanのプロフェッショナルモードで以下を確認してください。

- 反射原稿・原稿台・自動露出「書類向き」
- 24bitカラー・600dpi・等倍
- アンシャープマスクON、効果「中」
- モアレ除去・退色復元・逆光補正・ホコリ除去OFF

保存済みプリセットが表示される場合は選択できますが、単独アプリの設定を自動的に継承する保証はありません。画質設定はドライバー画面が優先されます。プレーヤー側のWIA用設定は無効表示になります。

このGT-S650ドライバーではCAP_CUSTOMDSDATA/設定のみのUIに対応していないことを確認したため、独自設定を推測した番号で書き込みません。EPSON固有の設定を確実に指定する場合は詳細設定画面を使用してください。高解像度の全面スキャンは大きなメモリーを使用します。

スキャン後、画像がプレーヤーの一覧に追加されます。原稿を交換して追加できます。ドライバー画面を閉じるとキャンセルできます。キャンセルで既存の取り込み済み画像は削除されません。

## 補正・保存

一覧の画像を選択し、90度回転、切り抜き・角度・歪み補正、ディスクの円形補正を使用できます。「元に戻す」は保存前の補正を戻します。

直線の外周は自動検出後に元画像の境界へ合わせ直し、余白が残りすぎるのを抑えます。薄い・不明瞭な境界は無理に縮めません。4点補正の角は丸の周囲もドラッグでき、表示倍率やウィンドウの大きさにかかわらず同じ広さでつかめます。辺もドラッグできます。少し離れた位置をつかんでも、角がマウス位置へ飛ぶことはありません。

保存形式の初期値はJPG（品質95）です。PNGも選択できます。補正中はPNGのまま保持し、最終保存時のみJPGへ変換するため、繰り返し編集でJPEG再圧縮は発生しません。保存名はFront.jpg、Back.jpg、Booklet001.jpg、Disc.jpg、Spine.jpgなどに変更できます。複数枚を確認した後「全画像をアルバムへ保存」を押してください。保存先は選択したアルバム内のImagesフォルダーで、存在しなければ自動作成します。既存の同名画像は上書きしません。

保存後のフォルダー画像更新では、曲を再解析せず既存の曲情報を維持します。Disc1/Disc2（CD1/CD2）を持つ通常の複数Discアルバムも一つのアルバムとして扱います。画像更新や読み取り失敗だけではライブラリからアルバムを削除しません。

フォルダー形式では新しい画像だけを追加します。ZIP/ZIP.MP3では既存音楽・画像・関連ファイルの内容を検証して再構築し、検証成功時だけ元ZIPを置き換えます。置換前のZIPは既存の7日バックアップ整理対象として残ります。音楽の再エンコードは行いません。

保存まで元アルバムは変更しません。未保存で画面を閉じる場合は確認後に、その画面専用の一時画像だけを破棄します。

## WIA（基本設定）

TWAINを使わない場合はWIAを明示的に選択できます。解像度、カラー/グレー/白黒、明るさ、コントラスト、白黒しきい値に対応します。EPSON独自のアンシャープマスク・モアレ除去・露出処理は指定できず、TWAINと同じ画質を保証しません。TWAIN失敗時に自動でWIAへ切り替えることはありません。
