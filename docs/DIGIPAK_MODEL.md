# デジパック2枚組（3面）モデル

Windows版の「トレイ」の右隣にある「ケース」で、アルバムごとに標準CDケース／デジパック2枚組を選択します。標準が初期値です。ケース設定は従来のcase-appearance.jsonに保存し、トレイ色を変更してもケース形式を維持します。音楽・スキャン元画像は変更しません。

## 3D表示と操作

3面の紙パネルと2枚のCDを収める透明トレーを表示します。開く順序は左表紙→右トレー、閉じる順序は右トレー→左表紙です。ブックレットは左面のポケットから上方向にスライドして取り出します。現在のCD取り出し操作では2枚を同時に取り出します。

鑑賞用の試作モデルであり、製造用CADの精度を保証するものではありません。

## 画像の対応

アルバム画像の「用途」で、Front、Back、Disc、Disc（2 Disc）、デジパック・左内面／右外面／トレー見開きを指定できます。側面の画像は「左Spine／右Spine」で割り当てます。手動で指定した用途を優先し、元画像は変更しません。画像がない面は仮素材になります。

## 対応範囲

対応するWindows開発版ではデジパックをGLB形式で出力し、Wi-Fi同期またはフォルダー出力でAndroidへ転送できます。Android 0.12.0以降は3面の順次開閉、2枚のCDの同時取り出し・戻し、ブックレットの上方向への取り出し・戻しに対応します。閉じる際はCDとブックレットを戻してからパネルを畳みます。標準ケースの既存データも引き続き読み込めます。

デジパックの転送には対応するWindows開発版とAndroid 0.12.0以降が必要です。Windowsの公開版v0.88.0はデジパックGLBの生成・転送に未対応で、Android 0.11.0以前も表示できません。旧形式のVCD3DではなくGLBを使用してください。

Androidの3D画面では「ケースを開く／閉じる」「CDを取り出す／戻す」「ブックレットを取り出す／戻す」を使用します。1本指で回転、2本指で移動、ピンチで拡大縮小できます。初期表示へ戻すと取り出した部品も元の位置に戻ります。デジパックには帯・包装の操作を適用しません。

汎用GLBビューアーでも開閉・取り出しアニメーションを再生できますが、折り目は簡略化した形状変化になります。Androidの専用ビューアーでは左右の折り目を曲面として変形します。
