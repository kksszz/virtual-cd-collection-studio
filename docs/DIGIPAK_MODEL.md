# デジパック2枚組（3面）モデル

Windows版の「トレイ」の右隣にある「ケース」で、アルバムごとに標準CDケース／デジパック2枚組を選択します。標準が初期値です。ケース設定は従来のcase-appearance.jsonに保存し、トレイ色を変更してもケース形式を維持します。音楽・スキャン元画像は変更しません。

## ActRaiser試作の実測値

閉じた外形139×124×11mm。紙パネル3枚は各138×124×1mm、左折り目12mm、右折り目10mm、全開の幅436mm。透明トレーは各136×124×4mm、左右余白1mm。保持部直径15mm、高さ3mm、円形くぼみ直径121mm。中心はトレー左端から67mm、上端から61.5mm。

左面の差し込み開口は幅125mm、左右6.5mm。追加の実物写真に合わせ、スキャンの線（下端から約24mm）に配置します。ブックレットは指定値120×120×0.05mmで、表側に見せ、下端だけをポケットの縁の裏へ収めます。上方向にスライドして取り出します。

開く順序は左表紙→右トレー。閉じる順序は右トレー→左表紙。折り目の曲面とトレーの細かい爪・指掛かりは写真からの近似であり、製造用CADの精度ではありません。CD取り出し操作は試作では2枚を同時に取り出します。

デジパックでは薄い紙面の自己影によるまだら表示を避けるため、影マップとSSAOを使用しません。直接照明・透明トレーの反射は維持し、標準ケースへ戻すと従来の影設定へ復帰します。左右の側面は外向きの法線で描画します。

画像を貼る紙面と側面は、紙本体の全面と重ねず画像面だけを描画し、深度競合によるチラつきを防止します。右Spineは外側から正しく読めるよう、UVの横方向を反転します。元画像は変更しません。

## 画像の対応

ActRaiserの既知のファイル名にのみ以下の対応を使用します。元画像を分割・上書きせず、描画時に範囲を選びます。手動で指定した用途はファイル名より優先します。

- Booklet001.jpg: 外表紙
- Booklet002.jpg: 中央面の外側（曲目）
- Booklet008.jpg / Booklet009.jpg: Disc 1 / Disc 2
- Booklet010.jpg: 左の内面（右の背部分を除く）
- Booklet011.jpg: 右の外面（右の背部分を除く）
- Booklet010.jpgの右端12mm相当: 左側面（黒い折り目）
- Booklet011.jpgの右端10mm相当: 右側面（文字入りの背）
- 側面専用画像がある場合は既存の「左Spine／右Spine」の用途指定を優先します。ない文字・絵柄は生成しません。
- Digipac001.jpg: トレー下の絵柄・トレーの見開きスキャン
- Booklet001〜007.jpg: ブックレット閲覧

他のアルバムでは用途Front、Back、Disc、Disc（2 Disc）、デジパック・左内面／右外面／トレー見開きを指定できます。画像がない面は仮素材になります。

今回の試作はWindows表示用です。Androidの従来モデル契約は1枚組のため、デジパック形式のエクスポートは未対応として明示的に拒否し、不正なモデルを作成しません。Android対応には別途3面・2枚組の開閉契約追加が必要です。
