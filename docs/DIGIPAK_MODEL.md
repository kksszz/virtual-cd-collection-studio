# デジパック2枚組・3枚組モデル

Windows版の「トレイ」の右隣にある「ケース」で、アルバムごとに標準CDケース／デジパック2枚組／デジパック3枚組を選択します。標準が初期値です。「冊子の取り出し」では、ディスク枚数とは独立して「上へ」「左へ」を選択できます。2枚組の初期値は「上へ」、新規に3枚組を選んだときは「左へ」です。設定は `case-appearance.json` に保存し、トレイ色を変更してもケース形式と冊子方向を維持します。音楽・スキャン元画像は変更しません。

## 3D表示と操作

2枚組では3面の紙パネルと2枚のCD、3枚組では4面の紙パネルと3枚のCDを収める透明トレーを表示します。3枚組は左表紙→中央右パネル→最右パネルの順に開き、逆順で閉じます。ブックレットは選択した方向へスライドします。現在のCD取り出し操作では、そのケースのディスクを同時に取り出します。

3枚組モデルの閉じた外形は約139×124×19mm、開いた幅は約597.5mmです。3か所の折り目は左から18mm、16.5mm、11mmとしてあります。実物の3枚組写真・計測値に基づく鑑賞用寸法です。

鑑賞用の試作モデルであり、製造用CADの精度を保証するものではありません。

## 画像の対応

アルバム画像の「用途」で、Front、Back、Disc、Disc（2 Disc）、Disc（3 Disc）、デジパック・左内面／右外面／最右外面／トレー1・2・3／トレー見開きを指定できます。側面の画像は「左Spine／右Spine／デジパック・3番目の折り目」で割り当てます。トレー見開きは2枚組では2分割、3枚組では3面の横長スキャンのみ3分割します。個別トレー画像があればそちらを優先します。手動で指定した用途を優先し、元画像は変更しません。画像がない面は仮素材になります。写真だけでは印刷面を復元できないため、実物どおりの表示には各面・盤面のスキャン画像が必要です。

## 対応範囲

デジパックはGLB形式で出力し、Wi-Fi同期またはフォルダー出力でAndroidへ転送できます。新しい3枚組GLBプロファイルには3枚目のパネル・ディスク・折り目と冊子の取り出し方向を含めます。Android側でも同じ順序で開閉し、冊子を選択方向へ取り出します。閉じる際はCDとブックレットを戻してからパネルを畳みます。標準ケースおよび従来の2枚組データも引き続き読み込めます。

3枚組と冊子方向の切り替えには、この機能を含むWindows・Android両方の更新版が必要です。更新後にWindowsで転送データを再準備し、GLBを再転送してください。旧形式のVCD3DではなくGLBを使用します。

Androidの3D画面では「ケースを開く／閉じる」「CDを取り出す／戻す」「ブックレットを取り出す／戻す」を使用します。1本指で回転、2本指で移動、ピンチで拡大縮小できます。初期表示へ戻すと取り出した部品も元の位置に戻ります。デジパックには帯・包装の操作を適用しません。

汎用GLBビューアーでも開閉・取り出しアニメーションを再生できますが、折り目は簡略化した形状変化になります。Androidの専用ビューアーでは折り目を曲面として変形します。端末での3枚組実描画は、実物のスキャン画像を割り当てた後に追加確認します。
