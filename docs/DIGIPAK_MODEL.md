# デジパック2枚組（3面）モデル

Windows版の「トレイ」の右隣にある「ケース」で、アルバムごとに標準CDケース／デジパック2枚組を選択します。標準が初期値です。ケース設定は従来のcase-appearance.jsonに保存し、トレイ色を変更してもケース形式を維持します。音楽・スキャン元画像は変更しません。

## 3D表示と操作

3面の紙パネルと2枚のCDを収める透明トレーを表示します。開く順序は左表紙→右トレー、閉じる順序は右トレー→左表紙です。ブックレットは左面のポケットから上方向にスライドして取り出します。現在のCD取り出し操作では2枚を同時に取り出します。

鑑賞用の試作モデルであり、製造用CADの精度を保証するものではありません。

## 画像の対応

アルバム画像の「用途」で、Front、Back、Disc、Disc（2 Disc）、デジパック・左内面／右外面／トレー見開きを指定できます。側面の画像は「左Spine／右Spine」で割り当てます。手動で指定した用途を優先し、元画像は変更しません。画像がない面は仮素材になります。

## 対応範囲

今回の試作はWindows表示用です。Androidの従来モデル契約は1枚組のため、デジパック形式のエクスポートは未対応として明示的に拒否し、不正なモデルを作成しません。Android対応には別途3面・2枚組の開閉契約追加が必要です。
