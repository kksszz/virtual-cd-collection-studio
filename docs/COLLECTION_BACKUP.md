# 完全バックアップ（Windows開発版）

設定画面の「音楽ライブラリ」にある「完全バックアップ…」から作成・確認・復元します。現行公開版 v0.89.0 にはまだ含まれません。従来の「管理データをバックアップ／復元」も残していますが、形式と対象が異なります。

## 対象と選び方

| 対象 | 初期状態 | 内容 |
| --- | --- | --- |
| 管理データ | 選択済み | 設定、登録情報、履歴、お気に入り、取得画像、保存歌詞など |
| アプリ本体 | 未選択 | 実行中の版があるフォルダー。実行ファイル、付属ツール、説明資料など |
| 登録済み音楽フォルダー | 未選択 | 選んだフォルダー配下の音源、画像、歌詞など。非表示設定のフォルダーも一覧に表示 |

「設定・アプリ・音楽をすべて選択」で全対象を一括選択できます。「音楽フォルダーをすべて選択」は音楽だけ、「すべて解除」はすべてのチェックを外します。音楽フォルダーは1件ずつ変更できます。1800アルバム規模では容量と所要時間が大きくなるため、保存前に「対象のファイル数・容量を計算」で確認してください。

圧縮方式は高速（既定）／無圧縮／最大圧縮を選択できます。FLAC・MP3・JPEGなどは既に圧縮されているため、最大圧縮でも容量が大きく減るとは限りません。バックアップ先は対象フォルダーの外に指定し、空き容量のある外付けドライブなどを推奨します。対象内に保存すると中止します。

## 作成・検証

保存形式は `.vccsbackup` です。元ファイルを読み取り、作成時に各ファイルのSHA-256を記録し、完成前にアーカイブ全体を再検証します。成功したものだけ指定名へ確定します。既存のバックアップファイルは上書きしません。途中で失敗・中断した場合は、この処理が作った未完成ファイルを削除します。元の音楽・画像・設定は変更しません。

管理データではサムネイルキャッシュ、一時ファイル、過去の復元安全コピーを除外します。アプリ本体では開発用のPDBやログを除外します。音楽フォルダーは選択したフォルダー内のファイルと空フォルダーを対象にします。リンク／ジャンクションを含む対象は安全のため中止します。バックアップに暗号化はないため、保管場所へのアクセス権を管理してください。目録には元フォルダーの絶対パスも記録されます。

## 確認・復元

「確認・復元」で `.vccsbackup` を選び、「内容・SHA-256を検証」を押します。復元先には、まだ存在しない新しいフォルダー名を指定してください。復元時にもアーカイブを検証し、`Data`、`Application`、`Libraries/0001` などへ展開します。`RESTORE-README.txt` も生成します。既存のアプリ、稼働中の設定、元の音楽フォルダーは上書きしません。

展開したデータは自動的には現在のアプリへ適用されません。音楽を使う場合は復元先の音楽フォルダーを設定画面で登録してください。設定を別PCへ移す場合は、`Data` 内の設定を確認し、元PCの絶対パスを移行先に合わせて調整する必要があります。現段階ではアプリ本体・設定・音楽の一括自動切り替えは提供しません。復元先のファイルを確認するまで元データを消さないでください。

従来の `.zipmp3backup` は管理データ専用で、新形式と互換ではありません。従来形式は設定画面の「管理データを復元」から扱ってください。
