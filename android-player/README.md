# Virtual CD Player for Android — prototype 0.7.1

## ダウンロード

[Android 0.7.1プレリリース](https://github.com/kksszz/virtual-cd-collection-studio/releases/tag/android-v0.7.1) でAPKとSHA-256を配布しています。Android 10以上向けの試作・デバッグ署名版です。APKを端末へ保存し、インストールに使用するブラウザー／ファイル管理アプリに限って「不明なアプリのインストール」を許可してください。導入後は許可を戻せます。

同じ署名の既存試作版には上書き更新できます。署名が異なる等で更新できない場合は、設定や履歴・お気に入り・取り込んだ3Dデータを失うおそれがあるため、安易にアンインストールせず原因を確認してください。音源や実アルバム画像は同梱しません。Windows版は別のリリースです。

## 0.7.1 読み込み待ちの改善

- 全曲のタグ取得前にファイル名の仮一覧と曲数・進捗を表示。タグ取得後に正式な曲名・曲順に置き換え、曲の選択を有効化します。読み込み中も既存の再生操作は利用できます。
- ジャケット読み込みを曲情報の読み込みから分離。画像の処理が次のアルバムのタグ取得を待たせないようにしました。
- 別アルバムへ移動・一覧へ戻る際に不要な読み込みを中止。Android内部で実行中のメタデータ取得は即時中断できない場合がありますが、残りの曲は読みません。
- 最大1,000曲分のタグ情報をプロセス内で再利用。ディレクトリ内の音源一覧・各ファイルのサイズ・更新日時、ZIPのサイズ・更新日時を確認します。「再読込」はキャッシュを使わず取得し直します。アプリ終了後の永続キャッシュではなく、初回のSDカード読み取り時間は残ります。
- ジャケットを画面中央に保ち、3D・ジャケット・お気に入りを右側の縦アイコンに配置。主操作はシャッフル・前曲・再生/一時停止・停止・次曲・リピートの順です。
- 3D包装は薄いフィルム面・細い継ぎ目・開封テープの表現に変更しました。

このフォルダーはWindows版と同じリポジトリ内のAndroidプロジェクトです。音源、実アルバム画像、SDK/JDK、APK、端末の設定・履歴はリポジトリに含めません。

検証（Xperia 1 II、2026-09-19）：通常フォルダー14曲は仮一覧10ms・初回タグ取得484ms・キャッシュ再利用22ms、ZIP3曲は10ms・36ms・0ms（ミリ秒単位の計測）。これは今回の端末・サンプルに限る値で、SDカードや曲数・形式によって変わります。強制再読込、更新日時による無効化、キャンセル、再生状態保存、3D実描画のテストが通過しました。自動テストは `adb shell am instrument -w -e mode loading jp.virtualcd.player.test/jp.virtualcd.player.DeviceSmokeTest`（先に両APKをインストールし、アプリで通常フォルダーとZIPを含むMusicフォルダーへの読取許可が必要）。

## 0.7.0 詳細ケース・帯・包装

- 3Dとジャケットビューアーでマウスホイールの拡大/縮小に対応。3Dは左ドラッグで回転、ダブルクリックで初期表示。ジャケットは拡大中の左ドラッグで移動、ホイールはポインター位置を中心にズーム（3D 0.5〜3倍、画像1〜5倍）。従来のタッチ操作も維持。
- トレイの成形を改善：段差・斜面付き円形くぼみ、指掛け切り欠き、内周支持リング、分割された12本の保持爪を追加。透明トレイの背側は滑らかな面、不透明トレイは同材色の低いリブとする。実機GPUテストに透明トレイと単体トレイ描画、頂点/法線の有限値検証を追加。
- 曲画面の「3D」の隣に「ジャケット」ボタンを追加。選択アルバムの画像を既存の全画面ビューアーで読む。表紙タップも同じ入口を使用し、ページ切り替え・拡大・横/縦表示を維持。音源内の埋め込み画像はページ一覧の対象外。
- 3D画面下部に再生曲名と前曲・再生/一時停止・次曲・停止のコンパクトなアイコン操作を追加。既存の再生サービスに接続し、表示中の3Dアルバムとは独立して現在のキューを操作する。曲送り・通知側の操作にも表示が追従し、3Dの開閉だけでは再生状態を変更しない。
- CDの厚み・中心穴・透明ハブ・裏面の虹色反射、トレイの円形くぼみと保持爪、ケースのヒンジ・留め具・成形リブ、冊子の紙厚を追加。
- Windowsの帯画像を折り位置に従って表・背・裏へ分割し、幅を含めてv2パッケージへ出力。透明包装には折り目・継ぎ目・開封テープを表示。
- 「CD 出入」「帯 着脱」「包装 着脱」を追加。開く際は包装と帯を自動で外し、再包装時はCDを戻して閉じる。ダブルタップは向き・倍率・開閉・帯・包装を初期状態へ戻す。
- v1データも読み込み可能。帯の追加にはWindowsからv2で再出力・再取込が必要。反射と包装の動きは軽量な近似表現で、物理シミュレーションやWindowsのSTLそのものではない。
- Xperia 1 IIでv1/v2の検証・実描画・開閉連動テストを実施。Children Of Bodom「Are You Dead Yet? -Deluxe Edition-」の実データで帯・包装の着脱とCD取り出しを確認。

## 0.5.3 再生速度・ピッチ

- 「設定 → 音の設定」の上部に再生速度（0.50〜2.00倍、0.05刻み）、ピッチ（−12〜+12半音、1半音刻み）を追加。標準へ戻すボタンは両方を1.00倍/0半音に戻す。
- Media3のソフトウェア音声処理で速度と音程を独立制御。再生中に適用し、値は保存・再起動後に復元。原音忠実モードのEQ等のバイパスとは別の操作で、同モード中も使用可能。元ファイルの変更なし。
- 標準値以外の場合、再生時間の横にも現在の倍率と半音数を表示。表示する時間/シーク位置は音源上の位置であり、速度変更後の残り実時間ではない。大幅な速度/ピッチ変更では音色に処理感が出る場合がある。

## 0.5.0 音の設定と画面整理

- 右上の歯車「設定」に、音楽フォルダー/単体ファイル選択、ライブラリ全体の再読込、音の設定を集約。

### 音の設定

- ギャップレスON（既定）：Media3の連続再生。OFF：曲末まで排出してから次曲を開始。リピート/シャッフルに従い、明示的な一時停止から勝手に再開しない。音源内の無音を除去する機能ではなく、すべての形式/異なるサンプルレート間で完全な無音ゼロを保証するものではない。
- 原音忠実モード（既定ON）：アプリ内補正をバイパスし、各設定値は保持。初期状態は補正なし。以下を使うときはOFFにする。
- 音質向上：OFF/軽め/標準/強め/劇的/HDR風。Windows版のトーン・倍音・エンベロープ・ステレオ幅のプロファイルを移植。失われた音源情報の復元やSony固有の処理ではない。
- 音量ノーマライズ：ステレオ連動RMS、目標−18 dBFS、補正−18〜+9 dB、無音ゲート、緩やかなゲイン変更。LUFS事前解析/ReplayGainではない。
- 小音量クリア、10バンドEQ（31 Hz〜16 kHz、±12 dB、プリセット/リセット）、EXTRA BASS風（0〜100%）。ナイキスト周波数付近/以上のEQ帯域は適用しない。
- 全補正はリアルタイムかつ非破壊。設定変更は20 msでクロスフェードし、補正中のピークはチャンネル連動で保護。設定はアプリ内へ自動保存し、サービス/アプリ再起動時に復元。
- 本実装はMedia3のソフトウェアPCM16経路を使用する。原音忠実モードは「アプリ内DSPなし」であり、24bit/ハイレゾやOS/端末の音質効果を含むビットパーフェクト出力を保証しない。ビジュアライザーは追加しない。

検証：`test-core.ps1` にDSPのバイパス、各周波数/全プロファイル、無音、ピーク保護、EQ応答、RMS目標/ステレオ連動を追加。実機テストは独立した保存領域を使用し、音源は読み取り専用・再生はミュート。WAV/M4A実音源、聴感、電池消費、全ライブラリの確認は別途必要。

## 0.4.0 再生状態・履歴・お気に入り

- 再生キュー・曲・位置をアプリ内に保存。位置は5秒ごと、シーク・曲変更・一時停止・サービス終了時にも保存。強制電源断等では最後のチェックポイントまでとなります。
- 起動時は保存した曲/位置と元のアルバム画面を復元し、自動再生しません。「再生」で続きから開始。SDカード抜去・権限解除・音源移動時はエラーを表示し、保存情報は勝手に削除しません。
- 「履歴」は最後に再生した曲が先頭。同じ曲は重複せず、最新200曲を保存。選ぶと元アルバムのその曲から再生します。
- アルバム/曲のお気に入りを保存（操作は0.5.0で専用の☆/★ボタンに統一）。お気に入り一覧でアルバム/曲を選べます。
- 「乱順」は現在の再生キュー内のシャッフル。「反復」はOFF→1曲→全曲。両方の設定を再起動後も維持します。シャッフル順そのものは再生成されます。
- Xperiaの独立したテスト用保存領域で、キュー/65秒位置/モード復元、アルバム識別情報、履歴の順序・重複抑制・200曲上限、お気に入りの永続化・解除を検証済みです。ユーザーの履歴やお気に入りはテストで変更しません。

## 0.3.0 通常ファイル・FLAC対応

- Music配下を再帰走査し、通常のMP3／FLAC／WAV／M4Aが直接入っているフォルダーをDIRアルバムとして一覧化。ZIPと並べて表示します。複数Discが別フォルダーなら現時点では別アルバムです。
- タグ読込は選択したアルバムだけで実行。曲名・アルバム名・アーティストを表示し、Disc番号→曲番号→自然なファイル名順で並べます。タグなしでも再生できます。
- 通常ファイルはAndroidの読み取り権限を用いて直接再生。無圧縮ZIP内も同じ4形式に対応（拡張子は音声形式そのものではなく格納形式を示す）。再圧縮・再エンコード・削除なし。
- DIRのジャケットは同じフォルダー、ジャケ／Artwork／Cover／Scan／Booklet等の画像サブフォルダー（2階層まで）、または先頭曲の埋め込み画像から取得。外部画像はタッチビューアーにも対応。
- 「ファイル」から単体MP3／FLAC／WAV／M4Aを開けます。CUEによる1ファイルの曲分割、ISO／BINは今後の段階です。
- Xperia内の実ファイルでFLAC／通常MP3／ZIP内MP3を無音の自動テストで確認（デコード、再生位置進行、途中へのシーク）。WAV／M4Aは形式対応とビルドまでで、この端末の実音源による確認は未実施。音質評価や全1,448 FLACの再生保証とは異なります。

Windows版との段階的な機能対応計画は `WINDOWS_PARITY.md` を参照してください。

実機走査の結果: Music配下の168アルバム（DIR 166 + ZIP 2）を検出。`DeviceSmokeTest`でFLAC/MP3/ZIP各1サンプルの再生・シークが成功（INSTRUMENTATION_CODE -1）。ユーザーの既存読み取り許可を使い、テストは永続索引を変更しません。更新後は「再読込」で一覧へ反映してください。

## 0.2.4の画像ビューアー

曲名表示では、ID3v2.3の文字コード0にCP932日本語を格納した古いタグの互換読取を追加。Latin-1の制御文字域を含み、厳密なCP932変換で日本語になるタイトルに限定します。UnicodeタグやASCIIは既存の読取に任せます。MELODIESの「突然」の実ファイルで読取テスト済み。タグは変更しません。

- 全画面表示。画像を1回タップするとファイル名と操作ボタンを隠す／再表示。
- 全体表示中は左スワイプで次、右スワイプで前。ゆっくりしたドラッグでも切り替え可能。
- ピンチで1〜5倍に拡大・縮小、ダブルタップで拡大／全体表示。拡大中のドラッグは画像移動となり、ページは切り替えません。
- 端末の自動回転に対応。「横／縦」ボタンで明示的にも切り替え可能。回転時もページと再生を維持し、画像を画面内に合わせ直します。閉じると元の画面向き設定へ戻します。
- 読込中の連続ページ操作を抑制し、一度に1枚だけ読み込みます。画像データは変更しません。

## 0.2.3の変更

- 曲一覧と再生用MediaItemは曲名タグを優先。空／読取不能の場合のみ拡張子を除いたファイル名を使用。並び順はこれまで通りファイル名順です。タグと音源は変更しません。
- アルバム画面のジャケットをタップすると画像ビューアーを表示。「前へ」「次へ」でZIP内のJPEG／PNG／WebPを切り替え、枚数とファイル名を表示します。再生は継続します。
- ビューアーは見開きを切らず画像全体を最大1600pxで表示。1枚ずつ非同期読込、元画像8MBまで。MP3埋め込み画像はこの画像一覧の対象外です。
- 上部操作ボタンは「ファイル／フォルダー／一覧へ／再読込」の等幅1行です。

## 0.2.1の表示変更

- 一覧の表紙は96dp、縮小画像は最大384px。約2:1の横見開きはWindows版のRightHalf処理と同様、右端の正方形を表紙として表示。画像全体や左側を使いたい場合はアルバムを長押しして変更可能。設定はAndroid側だけに保存し、画像そのものは変更しません。
- アルバムを開くと、再生操作などの固定領域を除いた中央部分を上下50:50に分割。上半分に表紙・アルバム名・アーティスト名・曲数、下半分にスクロールできる曲一覧を表示します。タグがなければファイル名を使用します。
- Windows側の手動画像設定を転送する機能はまだありません。自動判定の異なる見開きは長押しで表示範囲を指定してください。

Xperia 1 IIの有線イヤホンで、Windows版の無圧縮ZIP.MP3を再エンコードせずに再生する試作です。Windows版のコード・設定・音源は変更しません。

## 現在の試作範囲

- SDカードのMusicなどのフォルダーを選択し、サブフォルダーのZIP.MP3／ZIPと通常のMP3／FLAC／WAV／M4Aフォルダーをバックグラウンドで一覧化。権限は読み取りのみ。
- アルバム一覧・ファイル名検索・曲一覧への移動。「一覧へ」で戻り、「再読込」で追加ファイルを検出。
- 一覧索引をアプリ内へ原子的に保存し、次回起動時に復元。読込失敗時は前回の一覧を保持。
- ZIP内のFront／Cover画像を優先し、なければ先頭MP3の埋め込み画像を試す。表示時に非同期で最大384pxへ縮小、8MBのメモリーキャッシュを使用。画像なしはディスクアイコン。画像の展開ファイルは作らない。
- システムのファイル選択画面で、SDカードのZIP.MP3を1枚選ぶ（読み取り権限のみ）。
- ZIPの中央ディレクトリからMP3の位置とサイズを取得。展開ファイルを作らず、曲の範囲だけをMedia3へ渡す。
- 曲一覧・再生・一時停止・停止・前後の曲・シーク・再生位置表示。
- MediaSessionServiceによるバックグラウンド再生の実装、オーディオフォーカスとイヤホン切断への対応。
- 独自EQ、ノーマライズ、再エンコード、通信権限なし。

2026-09-18に0.2のデバッグAPKのビルド・Lint（エラー0件、警告16件）・ZIP／画像索引の単体テストが成功し、Xperia 1 II（XQ-AT52）に更新インストール・起動しました。0.1ではユーザーが直接再生・シーク・画面消灯時の継続・次曲切替を確認済みです。0.2のフォルダー選択・一覧表示はユーザーのSDカードアクセス許可後に確認します。ソニーのDSEEやDolbyとの互換性、ギャップレス、音質比較はまだ未確認です。

APK: `app/build/outputs/apk/debug/app-debug.apk`（試作・デバッグ署名）。公開配布版ではありません。Lintには翻訳用リソース化・新しい依存関係・バックアップ設定などの警告が残っています。

全曲横断検索、3Dカバーは今後の開発項目です。圧縮音声エントリー・暗号化ZIP・ZIP64・分割ZIP・CUE/ISOは未対応です。ZIPは拡張子で一覧に載せ、曲一覧を開く時点で再生対応形式かを検証します。Google Drive等のシークできないプロバイダーではなく、SDカード内のファイルを選んでください。画像は8MBまでのJPEG/PNG/WebPが対象です。PC側の画像用途指定はまだ未連携です。

## アルバム一覧の使い方

1. 「フォルダー」を押す。
2. SDカードの「Music」を選択し、「このフォルダを使用」→「許可」。SDカードのルートではなくMusic等のサブフォルダーを指定してください。
3. 一覧のアルバムをタップし、曲名をタップして再生。
4. 音源を追加した後は「再読込」。ファイルをコピー・変更・削除する機能ではありません。

## 構成と3D拡張計画

- `archive/StoredZipIndex`：Androidに依存しないZIP索引・範囲検証。
- `archive/ZipTrackDataSource`：Androidの読み取り権限を使った、曲単位のシーク可能な入力。
- `PlaybackService`：画面とは独立した再生。将来の3D画面からもMediaController経由で操作する。
- `MainActivity`：試作の2D曲一覧。後でアルバム表示に置き換えてもZIP入力や再生処理を変えない。

次段階でAlbum/Track/Artworkモデルと永続索引を追加し、PC側のジャケット割り当て（Front/Back/Spine/Disc）を持ち出し用マニフェストで受け取る設計とします。3D用画像は低解像度の別キャッシュにし、表示範囲だけを読み込みます。WindowsのWPF/HelixToolkit描画コードはAndroidへそのまま移植せず、描画部分を別実装にします。

## 開発環境

- JDK 17（このプロジェクトの`.tools/jdk`に配置。PCの既存Java設定は変更しない）
- Gradle 8.13 / Android Gradle Plugin 8.13.2
- Android SDK Platform 36 / Build Tools 35.0.0
- Media3 1.9.4 / Android 10以上（minSdk 29）

SDKライセンスへのユーザー同意を受け、SDKとGradleを`.tools`に導入済みです。PowerShellで`./build-android.ps1`を実行するとAPK作成とLintを実行します。スクリプトはプロジェクト専用環境を使用し、終了時に環境変数を復元します。Gradle Wrapperも生成済みで、標準環境では`./gradlew.bat :app:assembleDebug :app:lintDebug`を使用できます。Android Studioからこのフォルダーを開くこともできます。

ZIP読み取りの単体テストは`./test-core.ps1`。テストは一意な一時フォルダーに合成ZIPを作り、元音源を変更しません。追加引数にZIPのパスを渡すと、読み取りのみで索引を確認できます。

## Xperiaでの確認手順

1. 開発環境の導入・APKビルドは完了。Xperia 1 IIをUSB接続して確認済み。
2. ビルド検証後、XperiaでUSBデバッグを有効にしてPCへの接続を許可。
3. デバッグAPKをインストール。まず1枚の無圧縮ZIP.MP3で試す。
4. 全曲の先頭・中間・末尾へのシーク、前後曲、画面消灯、イヤホン抜去を確認。
5. 純正ミュージックと同一MP3・同一音量・同一補正設定で比較。音量差を音質差と取り違えない。

この段階では大量転送や元ファイル削除は行いません。
