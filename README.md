# Virtual CD Collection Studio

Third-party assets and their licenses are listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

CDの音楽だけでなく、ジャケット、Spine Card（帯）、ブックレット、ディスク、包装まで丸ごと保存・鑑賞・再生するWindows向けCDコレクションライブラリです。ZIP.MP3アルバムと一般的な音声ファイルの管理・再生にも対応しています。

## 主な機能

- ZIP / ZIP.MP3内のMP3を展開管理せずに一覧化・再生
- 圧縮ZIP.MP3を無圧縮ZIP.MP3へ変換
- CBR/VBR MP3、WAV、FLAC、M4Aの再生（VBR MP3の時間指定頭出しに対応）
- 次の曲を先読みするギャップレス再生（アルバム間・お気に入り一覧にも対応）
- アルバム画像、歌詞、LRC同期表示と自動スクロール
- アルバム／曲のお気に入り、検索、再生履歴・利用統計
- 再生履歴ダッシュボード（アーティスト・アルバム・曲のランキング）
- アルバムの右クリック「プロパティ」で保存場所・サイズ・日時・音声情報を確認（場所を開く／パスのコピー）
- 曲一覧・お気に入りの曲も右クリック「プロパティ」に対応。ZIP内の曲はZIPの場所と内部ファイル名・圧縮前後のサイズを区別して表示します（音声情報とZIP内サイズは登録時の情報）。
- 3Dカバーフロー、CDラック、CDケースの開閉・CD取り出し、包装開封、画像パーツの手動割り当て
- 全画面アルバムブラウザー（タイル／3D CoverFlow／CDラック、検索・選択・再生を同期）
- タグの一括編集、表形式コピー＆貼り付け、任意バックアップ
- タグ編集画面の「全曲の英数字・空白を半角に」でアルバム全曲の全角英数字・全角スペースを変換。変換時に日本語・記号・スペースの数・ファイル名は変更せず、結果を確認して「まとめて保存」で反映します。
- 原音忠実モード、イコライザー、低音量向け補正、ビジュアライザー
- 日本語／英語表示
- 設定・履歴・歌詞・追加画像などのバックアップと復元

## 動作環境

- Windows 10 / 11
- .NET 10 SDK（ソースからビルドする場合）

## ダウンロードと起動

[GitHub Releases](https://github.com/kksszz/zip-mp3-player-and-manager-plus/releases) の
Windows x64用ZIPを展開し、`Virtual CD Collection Studio.exe` を起動してください。
配布版には.NET実行環境を同梱しています。更新前に起動中の旧版を終了してください。
設定・履歴は既存のデータ保存先を引き続き使用します。

## 3Dカバーフローの操作

アルバム欄右上の「⛶」から全画面アルバムブラウザーを開けます。「タイル」では画面全体へジャケットを並べ、「3D CoverFlow」では中央の前面ケースと左右最大12枚ずつの立体CDケースを扇状に並べて選択します。「CDラック」は未選択ケースをSpine正面で密に収納し、選択ケースだけを手前へ引き出してFrontを確認できる配置です。アーティスト順／アルバム名順のソートはタイルと両3D表示へ同時に反映され、選択中のアルバムを維持します。共通の頭文字バーから「すべて」「★お気に入り」「#数字」「A～Z」「あ～わ」「漢字」「その他」を選べます。アーティスト順ではアーティスト名、アルバム名順ではアルバム名の頭文字を使い、英字のアクセント記号、ひらがな・カタカナ・濁音も同じ系列へまとめます。アルバム名・アーティスト名の検索欄は右端の×で入力を消去できます。タイル画面上部のサイズスライダーは、操作中もジャケットの大きさと折り返し列数をリアルタイムに変更します。タイルはホイール操作を慣性付きのピクセルスクロールで補間し、ポイント時の浮き上がりと検索・ソート更新時の短いフェードを加えています。CoverFlowとCDラックの閉じたケース外形は通常の3D Viewと同じSTLモデルを共有し、Front・Back・左右Spineだけを各外面へ貼る軽量構成です。白いジャケットが飽和しないようコレクション表示だけ照明と印刷面の反射を抑えています。選択中は1600px、左右の表示対象は960pxのケース画像を非同期で読み込み、縮小時は高品質補間してセッション内で再利用します。ケースモデルを再作成せず保持し、選択が変わるたびに位置・角度・奥行き・大きさを約430ミリ秒かけて連続補間します。各表示の検索・選択状態は同期し、クリックで選択、ダブルクリックまたはEnterで全画面表示を維持したまま先頭曲を再生します。Escまたは「閉じる」で元の画面へ戻ります。

- 左ボタンドラッグ：回転
- 中央ボタン（ホイール押し込み）ドラッグ：上下左右へ移動
- R：移動位置を中央へ戻す
- ホイール：通常表示ではアルバム切り替え、全画面ではズーム
- F11：全画面切り替え、Esc：全画面を閉じる
- C：ケース開閉、D：開いたケースからCDを取り出す／戻す

Back・Spineの画像がない場合は無地で表示します。
アルバム検索は入力が約180ミリ秒落ち着いてから結果を更新します。日本語変換中の再検索や非表示のツリー・3D更新を抑え、一覧は表示範囲だけを描画します。カバーフローの画像はバックグラウンドで読み込みます。
「Spine付きBack」などの割り当てはアルバム画像のパーツ設定から指定できます。
Inlayはトレイ下の内向きの面に表示します。左右Spineを含む横長のスキャンは中央と左右に分割して折り返します。
Inlay画像が存在する間は、トレイを自動的に「透明」に選択します。既存アルバムや用途変更にも適用され、Inlayを外すと以前のトレイ色設定に戻ります。
取り出したCDは、盤面を左ボタンでドラッグすると画面上を自由に移動できます。CD以外を左ドラッグすると従来通りケースを回転します。「CDを戻す」またはケースを閉じるとCDは元の位置に戻ります。
Front見開き、Front縦見開き、または個別のFrontとFront背面があるアルバムでは、3Dビューの「ジャケットを見る」から冊子を取り出して開き、閲覧モードへ進めます。通常のFront見開きは左＝Front背面／右＝Front、特殊なFront縦見開きは上＝Front／下＝180度回転したFront背面として扱います。閲覧順はFront（最初）、PAGE（冊子ページ）、ライナーノーツ、Flyer、Front背面（最後）です。Flyerはこのジャケット閲覧に含め、Posterは用途分類として保存しますが冊子ページや3Dケース面には使用しません。個別のFrontとFront背面が両方あれば見開き画像は表示にも開始演出にも使いません。個別画像が不足する場合だけ、割り当てた見開き画像から補完します。3Dケースでは単独Frontより見開きから切り出したFrontの解像度が同等以上なら見開きを使い、Front背面も同じ画像から保持します。アルバム一覧アイコンは見開きのFront側を最優先にし、派生サムネイルをキャッシュします。見開き画像には中央の綴じ目、紙端の陰影、ページ影を加えます。ページ送りでは旧ページを32分割したポリゴンメッシュとして次ページの上へ重ね、外端から移動する折れ目で半分を立ち上げ、綴じ側へ回り込ませます。前ページは次ページの読み込み完了まで保持し、ページの不透明度を変えないため暗転やフラッシュも抑えています。左右矢印でページ送り、ホイール・＋／−で拡大縮小、ドラッグで拡大画像を移動、Escで3Dへ戻ります。PAGE・Flyer・Poster画像は用途欄で指定でき、PAGE_01、flyer、posterなどのファイル名からも判定します。
ジャケットは4点の爪の下をケース外側へ一冊分近く平行移動し、完全に抜けてから手前へ持ち上げます。「ジャケットを戻す」では、外側から逆の軌道をたどり、平らな状態で爪の下へ差し込みます。取り出し・差し戻しとも約2秒のアニメーションです。取り出したディスクはケース／トレイの手前側に制限され、ドラッグしてもケースを突き抜けません。
アルバム画像欄では、選択画像を左右90度ずつ回転して向きを保存できます。回転は元画像やZIP.MP3を書き換えない管理情報として保存され、画像一覧・拡大表示・3Dケース・冊子・OCR・自動トリミングへ共通して反映されます。「向きを戻す」で元の向きへ戻せます。
FLACは通常再生とアルバム間ギャップレス再生に対応しています。ギャップレス経路でMedia Foundationまたは出力ドライバーのコールバックエラーが起きた場合は、停止せず同じ曲・同じ位置から通常のFLAC再生へ自動的に切り替えます。
Spine付きBackとInlayは、外周の白いスキャン余白を検出してから中央面と左右Spineを切り出します。判別できない余白は残す保守的な処理で、元の画像ファイルは変更しません。
白いSpine上の文字はスキャン余白と区別して保持します。文字の位置が行ごとに変わる白領域は余白として切り落としません。
トレイを「透明」にするとInlayが透けて見え、不透明なトレイでは隠れます。
再生中もトレイの設定色は変わりません。
「ライナーノーツ」「Spine Card（帯）」は画像の分類として指定できます。Spine Cardは画像中央付近の縦の色境界・折り線を左右の対として検出し、スキャン位置の小さなずれやFront／Back幅の差も許容します。左のBack側フラップ、中央Spine、右のFront側フラップへ分割して3Dケースの外側へ巻き付けます。中央Spineをケースの物理的なSpine幅へ合わせ、その横方向の拡大率をFront／Back側にも適用します。縦方向は独立してケース内に収め、帯の上下が切れないように表示します。3D Viewerの「帯を外す」で折り畳まれた帯全体をケースから離れた左側へスライドし、開いたケースに隠れない位置へ置きます。外した帯はCDと同様に左ドラッグで自由に移動できます。ケースを開く場合は帯が完全に外れてから蓋が開き、帯を戻すとドラッグ位置もリセットされます。折り目を確実に判別できない場合は、中央16%をSpineとする保守的な分割を使います。ライナーノーツはケースの表紙・背表紙・Disc画像として自動転用しません。

通常の3D Viewerでは、Spine Card（帯）が登録されたアルバムだけ、ジュエルケースの外側に透明なキャラメル包装を表示します。ティアテープはケース下端寄りに配置し、右端の短いつまみはフィルム面から前方へ折れ曲がった形状です。開封は実物と同じ二工程です。まず右Spine下部のつまみを左へドラッグするか「テープを引く」（W）を押して、ケースにフィルムを残したまま細いティアテープだけを一周引き抜きます。次に切れ目からフィルムを上または左へドラッグするか「フィルムを外す」（W）を押し、透明フィルムを持ち上げてケースから外します。包装中はケース開閉と帯の取り外しをロックします。開封状態は同じViewer内ではアルバムごとに保持され、ケースと帯を元へ戻した後は包装を再表示できます。Spine Cardのないアルバムは包装を表示せず、そのままケースを開けられます。

## お気に入りから再生

上部の「★ お気に入り」で「お気に入りの曲」または「お気に入りアルバムの全曲」を選択できます。
検索・並べ替え後に「一覧を再生」、または曲をダブルクリックすると、表示順でアルバムをまたいで連続再生します。
前へ／次へ・リピート・シャッフルはこの一覧内で動作します。通常のアルバムから曲を再生すると通常再生へ戻ります。

## ギャップレス再生

拡張パネルの「ギャップレス再生」で切り替えます（初期設定ON）。次の曲を先読みし、曲が終わっても音声出力を作り直さず連続して再生します。クロスフェードではなく、曲同士を重ねずにつなぎます。

- 通常再生では、再生開始時に表示されていたアルバム順・各アルバムの曲順で、最後の曲から次のアルバムへ進みます。検索で絞った場合はその一覧が対象です。再生中の閲覧・検索ではキューは変わりません。
- お気に入りから開始した場合は、お気に入り画面で作った一覧内で動作します。リピート・シャッフルも再生キューが対象です。
- 通常モードではモノラル／ステレオとサンプルレートの違いを調整します。原音忠実モードでは、デコード後の音声形式が同じ場合に連続再生し、異なる場合は通常の切り替えを行います。マルチチャンネルの構成変更も通常切り替えです。
- MP3はMPEG-1（32／44.1／48 kHz）で有効なLAMEの遅延・余白情報がある場合だけ、圧縮時に加わった余白を補正します。情報のないMP3、MPEG-2／2.5のMP3やM4A等は出力の再起動による間はなくせますが、ファイル・デコーダー由来の余白が残る場合があります。音源に含まれる本来の無音は削りません。
- 遅いディスクや大きな圧縮ZIPなどで先読みが間に合わない場合は、通常の曲切り替えに戻ります。次の曲が壊れている／見つからない場合は再生エラーを表示します。
- OFFにすると従来のアルバム単位の再生に戻ります。手動の曲送り、シークや音質設定変更は完全な無中断を保証する対象ではありません。

## ビルド

```powershell
dotnet restore
dotnet build -c Release
```

単一実行ファイルとして発行する例:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

## データ保存

設定や管理データは、旧版との互換性を保つため、既定ではWindowsのローカルアプリデータ内にある `ZipMp3Player` フォルダへ保存します。名称変更後も登録済みライブラリ、画像、設定、履歴を引き継ぎます。音楽ファイル自体はバックアップ対象に含めません。

AIギターリメイク・カラオケ機能は現行の配布版から切り離しています。
AIモデルやその実行環境は同梱していません。

## 開発時の追加テスト

`dotnet run --project GaplessDevHarness` で、曲境界のPCM連続性、シーク・リピート、形式変更、ZIP内のCBR/VBR、LAME余白補正と画面連携を検証できます。テスト用エンコーダーはプレイヤー配布版には含めません。

手元の音源を使う任意テストでは、次の環境変数を設定できます。

- `ZIPMP3PLAYER_TEST_ARCHIVE`
- `ZIPMP3PLAYER_TEST_M4A`
- `ZIPMP3PLAYER_TEST_FLAC`
